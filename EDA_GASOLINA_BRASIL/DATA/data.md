### 📂 Fonte de Dados

O dataset utilizado nesta análise foi construído a partir das séries históricas da **ANP (Agência Nacional do Petróleo)**. Devido ao volume de dados e ao processo de limpeza realizado, o arquivo consolidado está hospedado no Kaggle:

🔗 **[Brazilian Gasoline Prices (2022-2026) no Kaggle](https://www.kaggle.com/datasets/marceloeduardo98/brazilian-gasoline-prices2022-2026)**

> **Nota:** No notebook, os dados de indicadores econômicos (Brent e Dólar) são consumidos em tempo real via API `yfinance`, permitindo uma análise sempre atualizada da correlação de preços.
